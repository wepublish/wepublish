# Submitting feedback about this skill

If following this skill led somewhere wrong — a stale instruction, a missing use case, a
step that didn't work — open an issue at
[github.com/puckeditor/skills/issues](https://github.com/puckeditor/skills/issues/new).

Include, briefly:

- what the user asked for, and which reference file was followed;
- the Puck version (`npm ls @puckeditor/core`) and the framework;
- what the skill said to do, and what actually happened.

If the problem is that Puck's own [docs](https://puckeditor.com/docs) were wrong or missing —
which is the more common cause — say so in the issue. Fixing the docs is usually the right
resolution, and the skill links to them rather than duplicating them.

Do not open an issue for something the user simply hasn't asked about yet.
