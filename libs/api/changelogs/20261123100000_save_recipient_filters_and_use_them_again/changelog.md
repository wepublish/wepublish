---
title: Save recipient filters and use them again
lead: A recipient filter can now be saved under a name with a description and loaded again later, in manual messages and in the manual assignment of the delivery channel.
actionRequired: false
---

Next to the recipient filter there is now a list **Saved filters**. It appears on the step where you choose the recipients, in **Manual messages** and in the manual assignment of the delivery channel. Both show the same list.

- **Save current filter** keeps the filter as it is set right now, under a name and an optional description.
- **Load** puts a saved filter back into the filter fields. You can still change it before you continue.
- **Overwrite with current filter** replaces what a saved filter selects and keeps its name.
- Name and description can be edited, and a saved filter can be deleted. Sends that were already started are not affected.

Each saved filter shows in short phrases what it selects.

**Good to know.**

- Saved filters are shared: everyone who may send manual messages or assign delivery channels sees and can change them.
- A filter with rolling dates, such as "more than 14 days ago", stays rolling. Loaded next month, it selects the people it applies to then.
- If a saved filter refers to a template, member plan or payment method that has been deleted since, that part is left out when loading and a note says so.
