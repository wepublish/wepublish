---
title: Télécharger les listes en CSV ou Excel
lead: La plupart des listes de l'éditeur disposent désormais d'un bouton « Télécharger » qui enregistre toutes les entrées correspondantes dans un fichier CSV ou Excel.
---

Le téléchargement reprend votre affichage actuel :

- **Toutes les entrées, pas seulement la page affichée.** Chaque ligne correspondant à vos filtres et à votre recherche est incluse, dans l'ordre de tri actuel.
- **Uniquement les colonnes visibles.** Les colonnes que vous avez masquées ne figurent pas dans le fichier.
- **Les dates restent des dates.** Dans les fichiers Excel, les dates sont de vraies cellules de date, que vous pouvez trier et filtrer.

Le bouton est disponible pour les articles, les pages, les commentaires, les utilisateurs, les événements, les sondages (votes), les codes de réduction et leur utilisation, les goodies, les consentements, les factures, les jetons API et le journal d'audit.
