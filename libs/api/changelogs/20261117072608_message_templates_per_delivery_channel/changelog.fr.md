---
title: Les modèles de message ont désormais une version par canal de distribution
lead: Un modèle peut désormais dire autre chose par e-mail et par lettre. Les « modèles d’e-mail » s’appellent maintenant « modèles de message », et la page d’édition a été réorganisée.
---

**Un modèle, une version par canal**

Si les lettres imprimées sont activées pour votre média, un modèle de message a désormais un onglet par canal de distribution : **E-mail** et **Lettre**. Chaque version a son propre objet et son propre texte. Une lettre n’a donc plus à reprendre la formulation de l’e-mail.

- **Ajouter la version lettre** crée la lettre comme copie de l’e-mail, que vous pouvez adapter.
- Le papier à lettres et les pages supplémentaires (PDF) appartiennent à la version lettre et n’apparaissent que sur son onglet.
- Chaque onglet a son propre aperçu. Un e-mail de test s’envoie depuis l’onglet e-mail.
- **Supprimer cette version** demande une confirmation avant de supprimer quoi que ce soit.
- Les modèles pour les messages de compte (lien de connexion, réinitialisation du mot de passe, changement d’e-mail) restent des modèles d’e-mail uniquement.

Vos modèles existants fonctionnent comme avant. Un modèle déjà envoyé sous forme de lettre a reçu une version lettre avec le même texte que son e-mail.

**Ce que cela change pour l’envoi**

- Une personne qui reçoit des lettres obtient la version lettre. Si un modèle n’a pas de version lettre, cette personne reçoit l’e-mail à la place.
- Sous **Messages manuels**, le canal de distribution suit le modèle choisi : un canal pour lequel le modèle n’a pas de version ne peut pas être sélectionné.
- Les messages automatiques et les e-mails système nécessitent un modèle avec une version e-mail.

**Également nouveau sur la page d’édition**

- Les usages ont des noms plus courts ; le ⓘ à côté explique à quoi sert chacun.
- Les espaces réservés sont regroupés sous des titres comme « Personne » et « Utilisateur », et le champ de recherche les filtre.
- La vue HTML est lisible en mode sombre.

**Corrigé :** activer ou désactiver « Aussi par lettre » pour un message automatique ne supprime plus son modèle.
