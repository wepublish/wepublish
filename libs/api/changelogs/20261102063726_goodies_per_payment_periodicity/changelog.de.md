---
title: Goodies pro Zahlungsintervall
lead: Ein Goodie kann neu auf bestimmte Zahlungsintervalle beschränkt werden, zum Beispiel ein Booklet, das es nur zum 2-Jahres-Abo gibt.
---

Im Goodie-Formular wählst du die Zahlungsintervalle, bei denen das Goodie angeboten wird. Lässt du das Feld leer, wird das Goodie wie bisher bei jedem Intervall seiner Abo-Pläne angeboten.

Auf der Website erscheint das Goodie erst, wenn die Leser:in eines dieser Intervalle gewählt hat, und die API lehnt ein Goodie ab, das nicht zum gewählten Intervall passt.
