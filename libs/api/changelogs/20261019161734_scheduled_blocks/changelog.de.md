---
title: Festlegen, wann Blöcke erscheinen
lead: Sie können jetzt bestimmen, wann ein Block auf der Website erscheint: in einem Zeitraum, an bestimmten Wochentagen oder zu einer Tageszeit. Ausserhalb dieses Zeitplans wird der Block automatisch ausgeblendet.
---

Klicken Sie bei einem Block auf das Uhr-Symbol, um seinen Zeitplan zu öffnen. Sie können kombinieren:

- **Zeitraum**: Der Block erscheint vom Beginn des ersten bis zum Ende des letzten Tags.
- **Wochentage**: Wählen Sie die Tage, an denen er erscheinen soll, oder keinen für jeden Tag.
- **Tageszeit**: Ein tägliches Zeitfenster in der Zeitzone der Website. Liegt das Ende vor dem Beginn, läuft das Fenster über Mitternacht, z. B. 22:00 bis 02:00.

Alle festgelegten Bedingungen müssen gleichzeitig zutreffen. Eine kurze Zusammenfassung zeigt Ihnen, wann der Block erscheint, und Blöcke, die gerade ausserhalb ihres Zeitplans liegen, sind als ausgeblendet markiert. Das funktioniert auch für Blöcke in Flex-Blöcken und Block-Vorlagen. Mit «Zeitplan entfernen» erscheint der Block wieder jederzeit.
