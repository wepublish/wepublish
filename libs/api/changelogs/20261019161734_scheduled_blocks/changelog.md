---
title: Schedule when blocks appear
lead: You can now set when a block shows on the website: on certain dates, on certain days of the week, or during a time of day. Outside its schedule the block is hidden automatically.
actionRequired: false
---

Click the clock icon on any block to open its schedule. You can combine:

- **Dates**: the block shows from the start of the first day to the end of the last.
- **Days**: pick the weekdays it should appear on, or none for every day.
- **Time of day**: a daily window in the site's time zone. An end before the start runs past midnight, e.g. 22:00 until 02:00.

All the parts you set have to apply at the same time. A short summary tells you when the block shows, and blocks that are currently outside their schedule are marked as hidden on the website. This works for blocks inside flex blocks and block templates too. Choose «Remove schedule» to show the block at all times again.
