---
title: Programmer l'affichage des blocs
lead: Vous pouvez désormais choisir quand un bloc s'affiche sur le site : à certaines dates, certains jours de la semaine ou à certaines heures. En dehors de ce calendrier, le bloc est masqué automatiquement.
---

Cliquez sur l'icône d'horloge d'un bloc pour ouvrir son calendrier. Vous pouvez combiner :

- **Dates** : le bloc s'affiche du début du premier jour jusqu'à la fin du dernier.
- **Jours** : choisissez les jours de la semaine où il doit apparaître, ou aucun pour tous les jours.
- **Heure** : une plage horaire quotidienne dans le fuseau horaire du site. Une fin avant le début passe minuit, p. ex. 22:00 à 02:00.

Toutes les conditions définies doivent s'appliquer en même temps. Un court résumé indique quand le bloc s'affiche, et les blocs actuellement hors de leur calendrier sont signalés comme masqués sur le site. Cela fonctionne aussi pour les blocs dans les blocs flex et les modèles de blocs. Choisissez « Retirer le calendrier » pour afficher à nouveau le bloc en permanence.
