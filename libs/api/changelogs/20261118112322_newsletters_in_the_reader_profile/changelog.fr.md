---
title: Les lecteur·rices choisissent leurs newsletters dans leur profil
lead: Sous Communication → Newsletters, tu définis les newsletters Mailchimp auxquelles tes lecteur·rices peuvent s'abonner. Les lecteur·rices connecté·es les choisissent ensuite dans leur profil, et les nouveaux formulaires newsletter démarrent avec ces mêmes newsletters.
---

La nouvelle page **Communication → Newsletters** liste les newsletters que tu proposes. Chacune est un intérêt de ta liste Mailchimp, avec le nom, la description et l'image facultative que voient les lecteur·rices. Tu peux en changer l'ordre. La page nécessite la synchronisation Mailchimp configurée avec une liste (sous Intégrations).

Active **Afficher les newsletters dans le profil** pour les montrer aux lecteur·rices. Les lecteur·rices connecté·es trouvent alors dans leur profil une section « Newsletter », avec une carte et une case à cocher par newsletter. En cochant une newsletter et en enregistrant, la personne est inscrite dans Mailchimp ; les nouveaux contacts reçoivent d'abord un e-mail de confirmation de Mailchimp. Désactivée, la section est masquée et les inscriptions dans Mailchimp restent inchangées.

Quand tu ajoutes une **Sélection d’intérêts** à un bloc **Formulaire newsletter** sur la même liste, elle démarre désormais avec ces newsletters : tu n'as pas besoin de les saisir à nouveau.
