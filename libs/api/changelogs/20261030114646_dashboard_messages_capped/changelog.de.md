---
title: Übersichtlichere Mitteilungen im Dashboard
lead: Das Dashboard zeigt neu höchstens vier Mitteilungen an, wobei jede Art von Mitteilung vertreten bleibt; über einen Link gelangen Sie zu den übrigen.
---

- Jede Art von Mitteilung (Connector-Hinweise, Team-Mitteilungen, Neuigkeiten und Aufgaben aus dem Changelog, Job-Fehler) behält mindestens einen Platz. Viele fehlgeschlagene Jobs verdrängen so keine Team-Mitteilung mehr aus dem Dashboard.
- Nur die wichtigste Mitteilung wird mit ihrem vollständigen Text angezeigt, die übrigen nur mit Titel und Aktionen.
- Gibt es weitere, führt ein Link wie «+3 weitere Mitteilungen» zur Mitteilungsseite mit allen Einträgen.
