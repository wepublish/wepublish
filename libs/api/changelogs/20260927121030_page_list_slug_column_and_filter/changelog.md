---
title: Find pages by slug in the page overview
lead: The page overview now shows the slug of each page and lets you filter by it. Via the column settings you can decide which columns are displayed.
actionRequired: false
---

- A new **Slug** column shows the URL segment of each page. It is visible by default.
- The filter bar has a new **Filter by slug** field. Partial entries are enough and upper/lower case is ignored.
- Using the column settings next to the page overview heading, you can hide columns you don't need — your selection is remembered for the next time.

The same column settings are also available in the article overview and in the invoice list of a subscription.
