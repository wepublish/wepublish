title: Compose newsletters in the editor
lead: Under Communication → Newsletter you can now assemble a newsletter from article teasers, text, images from the media library and info boxes, and push it into a Mailchimp draft with one click.
actionRequired: false
---

What you can do:

- Start a new issue from a ready-made layout and edit it block by block — the canvas shows the newsletter exactly as it will look in the inbox.
- Pick articles for teasers; headline, lead, link and image are always taken from the published article, so corrections reach the newsletter automatically.
- Pick images straight from the media library. They are sent in a format every mail client can show, including Outlook.
- Show blocks only to part of your audience (Mailchimp merge fields and groups).
- Check the size and the required footer links before sending, and open a preview of the finished mail.
- **To Mailchimp** creates or updates a draft campaign in Mailchimp. Sending stays a manual step in Mailchimp.

Publishing uses the Mailchimp integration under Settings → Integrations, so it has to be set up with an API key and an audience first. Editors and admins get the new permissions automatically; custom roles need the newsletter permissions added.
