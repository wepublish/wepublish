title: Newsletter im Editor zusammenstellen
lead: Unter Kommunikation → Newsletter stellen Sie einen Newsletter aus Artikel-Teasern, Text, Bildern aus der Medienbibliothek und Info-Boxen zusammen und übertragen ihn mit einem Klick in einen Mailchimp-Entwurf.
actionRequired: false
---

Was Sie tun können:

- Eine neue Ausgabe leer beginnen oder eine frühere duplizieren, um ihren Aufbau zu übernehmen, und Block für Block bearbeiten — die Arbeitsfläche zeigt den Newsletter genau so, wie er im Posteingang aussieht.
- Artikel für Teaser auswählen; Titel, Lead, Link und Bild kommen immer aus dem publizierten Artikel, Korrekturen gelangen also automatisch in den Newsletter.
- Bilder direkt aus der Medienbibliothek wählen. Sie werden in einem Format verschickt, das jedes Mailprogramm anzeigen kann, auch Outlook.
- Blöcke nur einem Teil des Publikums zeigen (Mailchimp-Merge-Felder und -Gruppen).
- Vor dem Versand Grösse und Pflichtangaben der Fusszeile prüfen und eine Vorschau der fertigen Mail öffnen.
- **An Mailchimp** erstellt oder aktualisiert einen Kampagnen-Entwurf in Mailchimp. Der Versand bleibt ein manueller Schritt in Mailchimp.

Für die Übertragung wird die Mailchimp-Integration unter Einstellungen → Integrationen verwendet; sie muss dafür mit API-Key und Publikum eingerichtet sein. Redaktion und Admins erhalten die neuen Berechtigungen automatisch, eigene Rollen brauchen die Newsletter-Berechtigungen zusätzlich.
