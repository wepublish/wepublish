---
title: A more accessible editor
lead: The editor now works much better with a keyboard and with screen readers, and error messages are easier to notice and fix.
actionRequired: false
---

We reviewed the whole editor against the WCAG 2.2 AA accessibility guidelines. Among the improvements:

- A **«Skip to main content»** link appears when you press Tab on any page, so you can jump straight past the sidebar.
- On phones, the menu now behaves like a proper overlay: the page behind it can't be reached by accident, and Escape closes it.
- Buttons that only show an icon, such as those in the rich text toolbar, table tools, pagination and poll answers, now have clear names for screen readers.
- Fields have visible labels instead of relying on placeholder text alone.
- When saving fails, the editor jumps to the block that needs fixing. Tabs with errors are marked as such.
- Failed logins and wrong 2FA codes now stay on screen until you change your input, instead of disappearing.
- Moving or deleting a block, or moving a dashboard card, is announced to screen readers.
- Date fields have a button to clear the date.
- An event can no longer end before it starts.
- Some colors, such as the highlighted entry in the sidebar, have more contrast.
