---
title: Nouvelle présentation de la page de peering
lead: La page de peering affiche désormais vos médias partenaires dans un tableau clair indiquant d’un coup d’œil le statut, l’URL de l’API et le site web de chaque peer.
---

- Une colonne **Statut** indique si chaque peer est *Actif* ou *Désactivé*.
- Chaque ligne affiche le logo et le nom du peer, son URL d’API et un lien cliquable vers son site web.
- Les actions modifier, activer/désactiver et supprimer sont désormais regroupées sous forme de boutons en fin de ligne. Pour les peers désactivés, le bouton de modification est grisé.
- Votre propre profil de peering apparaît maintenant dans une carte en haut de la page, avec un bouton **Modifier le profil** clairement libellé.
- Corrigé : un peer peut à nouveau être ouvert juste après la fermeture de son panneau de modification.

Également corrigé sur le site web : les images en plein écran dans la lightbox pouvaient parfois s’afficher de manière incorrecte. Elles s’adaptent désormais toujours à l’écran.
