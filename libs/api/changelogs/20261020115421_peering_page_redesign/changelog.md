---
title: Redesigned peering overview
lead: The peering page now lists your partner media in a clear table showing each peer's status, API URL and website at a glance.
actionRequired: false
---

- A **Status** column shows whether each peer is *Active* or *Disabled*.
- Each row shows the peer's logo and name, its API URL, and a clickable link to its website.
- Edit, enable/disable and delete are now grouped as buttons at the end of each row. For disabled peers, the edit button is greyed out.
- Your own peering profile now appears in a card at the top, with a clearly labelled **Edit profile** button.
- Fixed: a peer can be opened again right after its edit panel was closed.

Also fixed on the website: images in the lightbox fullscreen view could occasionally be displayed incorrectly. They now always fit the screen.
