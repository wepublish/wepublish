---
title: Numéros imprimés : listes d’impression avec livraisons, remise et compléments
lead: Sous «Numéros imprimés», vous saisissez chaque numéro imprimé, calculez à la date de parution qui reçoit un exemplaire, exportez la liste comme livraison, téléchargez son CSV et la marquez comme remise à l’imprimerie. Les livraisons remises comptent dans les numéros payés par chaque lecteur·trice.
---

Disponible pour les médias dont l’export d’impression est activé.

- **Chaque numéro est un enregistrement** : numéro, date de parution et note, dans un formulaire à côté de la liste des numéros. La liste montre le statut (Ouvert, Exporté, Clôturé, Historique), les livraisons, les exemplaires et qui a clôturé le numéro ; «Dupliquer» crée le numéro suivant avec les mêmes options. Qui reçoit un exemplaire se décide **à la date de parution**, pas le jour de l’export : un numéro de janvier liste les abonné·e·s de janvier.
- **Des options plutôt que des règles fixes** : par numéro, vous choisissez les plans, si bexio est lu (institutions, cadeaux, librairies, numéros à l’unité – via la clé du prestataire de paiement bexio sous Intégrations), si les lecteur·trice·s «en attente» avec un renouvellement impayé reçoivent un exemplaire et si les abonnements qui commencent après la date de parution reçoivent un exemplaire offert. Les valeurs par défaut se trouvent sous Paramètres → Plans ; chaque livraison conserve les options avec lesquelles elle a été calculée.
- **Calculer, vérifier, exporter** : «Calculer les exemplaires» enregistre la liste sur le numéro ; vous vérifiez les totaux et chaque adresse ; «Exporter les exemplaires» écrit exactement cette liste comme livraison avec son propre fichier CSV. Tant que la livraison n’est pas remise, un nouveau calcul la remplace – ou vous la supprimez. Une liste de plus de 24 heures doit être recalculée.
- **Remettre** : dès que le fichier est chez l’imprimerie, marquez la livraison comme remise. Elle est alors verrouillée et ses exemplaires comptent dans les numéros payés. Les corrections deviennent dès lors un **complément** : les mêmes étapes, uniquement avec les adresses absentes de toute livraison précédente – comme livraison à part avec son propre fichier. La liste complète de toutes les livraisons est disponible à tout moment.
- **Clôturer** : une fois toutes les livraisons remises, clôturez le numéro ; «Rouvrir» l’annule à tout moment si un complément s’avère nécessaire.
- **Exemplaires dus** : le paramètre «Numéros par an (imprimé)» et, par plan, «Numéros imprimés par période» (p. ex. 3 pour un abonnement d’essai) disent combien de numéros imprimés vaut une période payée. Une personne dont la période payée se termine reçoit encore des exemplaires jusqu’à ce nombre. Les numéros expédiés avant l’introduction arrivent par l’import comme numéros historiques, pour que l’année en cours soit juste.
