---
title: Text styles that adapt to screen size
lead: In the website theme you can now give each text style its own font size, line height and letter spacing for larger screens, and check the result in a live preview.
actionRequired: false
---

- **Screen sizes:** Each text style starts with a *Baseline* for small screens. Add screen sizes (sm, md, lg, xl) to change the font size, line height or letter spacing from a certain screen width upwards. Anything you leave switched off is taken from the next smaller screen size.
- **Base for all styles:** Values set here apply to every text style that does not set its own. The editor now tells you where an inherited value comes from.
- **Grouped list and preview:** Text styles are grouped into headings, text, teasers, article, banner and blocks. A preview shows all styles at the screen size you choose. Click a line in the preview to open that style.
- **Easier input:** Numbers can be typed freely and are only corrected when you leave the field. Use the arrow keys to adjust a value step by step, or hold Shift for bigger steps. Empty values now show «Default» instead of 0.
- Theme exports and imports include the new screen-size values.
