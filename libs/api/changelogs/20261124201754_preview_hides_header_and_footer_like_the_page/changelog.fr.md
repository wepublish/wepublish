---
title: L’aperçu masque l’en-tête et le pied de page comme la page
lead: Si une page masque l’en-tête ou le pied de page, son aperçu dans l’éditeur les masque désormais aussi.
---

Jusqu’ici, l’aperçu d’une page pas encore publiée affichait toujours l’en-tête et le pied de page du site, même avec **Masquer l’en-tête** ou **Masquer le pied de page** activé. L’aperçu ressemble maintenant à la page publiée.
