---
title: Jump anywhere with the command palette
lead: Press Cmd+K (Mac) or Ctrl+K (Windows) anywhere in the editor to search for a page or action and go there straight away.
actionRequired: false
---

Start typing what you are looking for, for example "articles", "new event" or "subscriptions", and pick a result with the arrow keys and Enter. You don't need to type the exact name: the palette also finds close matches.

The palette only shows what your account is allowed to open, and it also offers account actions such as logging out.
