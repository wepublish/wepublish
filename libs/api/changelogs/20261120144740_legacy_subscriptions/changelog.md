---
title: Legacy subscriptions: find them, message them, give them their own flow
lead: Subscriptions imported from your previous system now count as legacy subscriptions until their first payment here. You can filter them, send them a message and give them their own communication flow.
actionRequired: false
---

Available for media with legacy subscriptions switched on.

- **What counts as legacy.** A subscription imported from the previous system is a legacy subscription until the first invoice for it is paid here. The import date stays on record afterwards.
- **On the subscription.** An imported subscription's page says when it was imported and whether it has been paid for here since.
- **In the subscription list.** The filter «Legacy subscription» shows only legacy subscriptions, or only the others. The CSV export has the columns «importedAt» and «legacy».
- **In manual sends.** The audience can be narrowed to legacy subscriptions, for example to explain to them how to pay for the first time.
- **In communication flows.** A flow can be for legacy subscriptions, for all the others, or for both, which stays the default. A flow for legacy subscriptions only needs every message set up itself: the default flow does not fill in missing ones. Two flows for the same member plan no longer overlap if one is for legacy subscriptions only and the other for the rest.
