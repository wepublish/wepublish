---
title: We.Publish kann die Bexio-Rechnungen verschicken
lead: Bexio stellt Rechnungen von Erneuerungen nur noch aus, und We.Publish verschickt das Bexio-PDF mit der Mail oder dem Brief «Rechnung erstellt».
---

Die Bexio-Zahlungsintegration hat eine neue Einstellung, «We.Publish verschickt
die Bexio-Rechnungen». Ist sie aktiv, verschickt Bexio Rechnungen von
Erneuerungen nicht mehr selbst per E-Mail. Bexio stellt sie aus, und
We.Publish hängt das Bexio-PDF an die Mail «Rechnung erstellt» des
Abo-Ablaufs an – oder druckt es bei Leser:innen, die Briefe erhalten, nach dem
Brief. Leser:innen erhalten so eine Mail statt zwei, mit dem Wortlaut Ihrer
Vorlage, und das Mail-Log zeigt, ob sie zugestellt wurde.

Kann Bexio das PDF in einer Nacht nicht liefern, wird die Mail zurückgehalten,
das Mail-Log zeigt den Grund, und die Mail geht in einer der folgenden Nächte
hinaus, sobald das PDF verfügbar ist.

Prüfen Sie vor dem Einschalten den Text Ihrer Vorlage «Rechnung erstellt»: Er
sollte keine separate Mail von Bexio mehr erwähnen. In Bexio erscheint für so
verschickte Rechnungen kein E-Mail-Verlauf. Rechnungen aus dem Checkout
verschickt weiterhin Bexio.
