---
title: Preview links work again
lead: The copied preview link now opens the preview in the editor, and a new button opens the preview in its own tab.
---

In the preview of an article or page:

- **Copy preview link** now copies a link to the editor that opens straight in the preview, on the device you had selected. Previously the link led to the website and only showed «Vorschau nicht verfügbar» (preview not available) there. Anyone who opens the link needs to be logged into the editor and be allowed to see previews.
- **Open preview in a new tab** shows the preview on the website in its own browser tab.
