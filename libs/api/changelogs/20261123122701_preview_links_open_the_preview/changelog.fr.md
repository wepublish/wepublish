---
title: Les liens d’aperçu fonctionnent à nouveau
lead: Le lien d’aperçu copié ouvre désormais l’aperçu dans l’éditeur, et un nouveau bouton ouvre l’aperçu dans son propre onglet.
---

Dans l’aperçu d’un article ou d’une page :

- **Copier le lien vers l’aperçu** copie désormais un lien vers l’éditeur qui s’ouvre directement dans l’aperçu, sur l’appareil que tu avais choisi. Auparavant, le lien menait au site web et n’y affichait que « Vorschau nicht verfügbar ». La personne qui ouvre le lien doit être connectée à l’éditeur et avoir le droit de voir les aperçus.
- **Ouvrir l’aperçu dans un nouvel onglet** affiche l’aperçu sur le site web dans son propre onglet.
