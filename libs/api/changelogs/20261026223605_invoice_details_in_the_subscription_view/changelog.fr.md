---
title: Plus de détails sur les factures dans la vue d'abonnement
lead: Le tableau des factures d'un abonnement indique désormais quand chaque facture a été payée. D'autres détails, comme le moyen de paiement et le statut du paiement, peuvent être affichés via le menu des colonnes.
---

- **Payée le :** Le tableau des factures d'un abonnement indique la date de paiement de chaque facture. Les factures impayées affichent un tiret.
- **Plus de détails sur demande :** Ouvrez le menu **Colonnes** en haut à gauche du tableau pour afficher d'autres colonnes : payée via (moyen de paiement), statut du paiement, marquée payée par, annulée le, désactivation si impayée, créée le, dernière modification, e-mail de facturation et positions. Elles sont d'abord masquées pour que le tableau reste compact ; votre choix est mémorisé dans votre navigateur.
- **Les factures importées** ont été payées dans l'ancien système et n'affichent donc ni moyen ni statut de paiement.
- **Colonnes masquées par défaut dans d'autres tableaux aussi :** Les tableaux peuvent désormais proposer des colonnes supplémentaires masquées au départ. Affichez-les via le menu **Colonnes** ; **Réinitialiser les colonnes** les masque à nouveau.
