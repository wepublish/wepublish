---
title: Audience dashboard counts an upgrade only once
lead: When a reader switches to another plan, the audience dashboard now shows this only under "Replaced subscriptions", no longer also as a new and a deactivated subscription. In "Subscriptions to be renewed" and the renewal rate, the switch counts once, as a renewal.
actionRequired: false
---

A plan switch (upgrade) closes the reader's old subscription and creates a new one. The audience dashboard treats this as one event:

- **New paid subscriptions** no longer include subscriptions that replace another one.
- **Deactivated subscriptions** no longer include subscriptions that were closed by an upgrade.
- **Replaced subscriptions** is the only place where upgrades appear.
- **Subscriptions to be renewed** and the **renewal rate** contain each upgrade once, as a renewal. The old subscription no longer counts as a cancellation at the same time.

The dashboard recalculates all dates, so figures for past months change as well: fewer new and deactivated subscriptions, and a higher renewal rate for media where readers switch plans. Exports taken earlier will no longer match the current figures.

The explanations in the legend and in the table tooltips describe how upgrades count.
