---
title: Vorschaumodus mit Mobilansicht
lead: Seiten und Artikel können neu direkt im Editor in der Vorschau angesehen werden. Auch so, wie sie auf einem Mobilgerät erscheinen.
---

Beim Bearbeiten einer Seite oder eines Artikels können Inhalte über den bestehenden **Vorschau**-Button direkt im Editor angesehen werden.

Im Vorschaumodus kann zudem in eine Mobilansicht gewechselt und geprüft werden, wie die Seite auf einem Smartphone aussieht.
