---
title: Mode aperçu avec vue mobile
lead: Les pages et les articles peuvent désormais être prévisualisés directement dans l'éditeur. Y compris tels qu'ils s'affichent sur un appareil mobile.
---

Lors de la modification d'une page ou d'un article, le contenu peut être affiché directement dans l'éditeur grâce au bouton **Aperçu** existant.

En mode aperçu, il est également possible de passer à une vue mobile et de vérifier l'affichage de la page sur un smartphone.
