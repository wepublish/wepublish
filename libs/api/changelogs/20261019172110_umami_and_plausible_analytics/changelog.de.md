title: Umami-Tracking und mehr Anbieter für Hot & Trending
lead: Sie können Ihre Website jetzt mit Umami tracken. Hot & Trending kann die Seitenaufrufe neben Google Analytics nun auch aus Plausible oder Umami beziehen.
---

**Website-Tracking mit Umami**

Unter *Website-Einstellungen → Analytics* gibt es einen neuen Bereich für Umami. Aktivieren Sie ihn und geben Sie Ihre Umami-Website-ID ein, um Umami-Tracking zu Ihrer Website hinzuzufügen.

**Hot & Trending mit Plausible oder Umami**

Unter *Integrationen → Analytics* können Sie neben Google Analytics nun auch Plausible und Umami einrichten. Jeder Anbieter hat die neue Option **Für Hot & Trending verwenden**. Es kann jeweils nur ein Anbieter verwendet werden. Wählen Sie einen aus, wird die Option bei den anderen ausgeschaltet.

- **Plausible:** Geben Sie die Domain der Website und einen Stats-API-Schlüssel ein. Bei Plausible Cloud setzt die Stats API ein Business-Abo voraus.
- **Umami:** Geben Sie die Website-ID und einen API-Schlüssel ein.
- Wenn Sie Plausible oder Umami selbst hosten, können Sie zusätzlich dessen Adresse angeben.

**Bereich «E-Mail» entfernt**

Der Bereich *E-Mail* mit den Mailchimp-Einstellungen wurde aus den Website-Einstellungen entfernt. Die Integration *Mailchimp-Sync* ist davon nicht betroffen.
