title: Umami tracking and more providers for Hot & Trending
lead: You can now track your website with Umami, and Hot & Trending can get its page views from Plausible or Umami as well as Google Analytics.
actionRequired: false
---

**Website tracking with Umami**

Under *Website settings → Analytics* there is a new Umami section. Enable it and enter your Umami website ID to add Umami tracking to your website.

**Hot & Trending with Plausible or Umami**

Under *Integrations → Analytics* you can now set up Plausible and Umami next to Google Analytics. Each provider has a new **Use for Hot & Trending** option. Only one provider can be used at a time; choosing one turns the option off for the others.

- **Plausible:** enter the site domain and a Stats API key. On Plausible Cloud, the Stats API requires a Business plan.
- **Umami:** enter the website ID and an API key.
- If you host Plausible or Umami yourself, you can also enter its address.

**Mail section removed**

The *Mail* section with the Mailchimp settings has been removed from the website settings. The *Mailchimp Sync* integration is not affected.
