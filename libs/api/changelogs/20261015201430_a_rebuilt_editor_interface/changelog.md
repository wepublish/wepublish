---
title: A rebuilt editor interface
lead: The editor has been rebuilt on a single design system. It looks tidier and works the same, with a dark mode, list tables you can arrange yourself, and clearer article and page metadata.
actionRequired: false
---

**Everywhere**

- A dark mode that follows your system setting, switchable at the bottom of the navigation.
- The navigation, drawers, dialogs and form fields now come from one design system, so the same control looks and behaves the same wherever you meet it.

**Lists**

- Every list has a **Columns** menu: switch columns off that you do not need, drag them into the order you want, and the list remembers it for you.
- Filters sit behind a **Filters** button with the number of active filters on it and an × to clear them, so the fields are out of the way until you need them.

**Articles and pages**

- The metadata is grouped by what you do with it: Headline, Search engine, Byline and Publication, with the image next to the headline it belongs to.
- The social-media tab leads with the image and tells you which field it falls back to when you leave one empty.
- Autosave can be switched off in the editor header, and the choice is remembered for the next article.

**Settings**

- The website settings pages share one header, with the page name and its actions in the same place.
