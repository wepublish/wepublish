---
title: Les factures annulées apparaissent comme annulées sur la page de l’utilisateur
lead: Dans la liste des abonnements d’un utilisateur, une période dont la facture a été annulée affiche désormais « annulée » au lieu de « non payée », comme sur la page de l’abonnement.
---

Chaque période de la liste indique si sa facture est payée, annulée ou non payée.
