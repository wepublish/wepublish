---
title: Newsletter form with selectable interests
lead: Readers can now pick the interests they want to subscribe to, e.g. individual newsletters, shown as a list or as cards with an image and description.
---

In the **Newsletter form** block, add an input with the type **Interest selection** to a step. It lets readers choose which interests of the Mailchimp list selected under **General → List** they want to subscribe to. Select the list first, so its interests can be loaded.

- **Label:** the heading shown above the interests, e.g. "Which newsletters would you like to receive?"
- **Interest options:** add one option per interest. Each option gets a name (prefilled with the name of the Mailchimp interest), a description and an optional image.
- **Display as:** show the interests as a simple **list** with checkboxes or as a **grid with cards**.
- **Required:** readers must select at least one interest before they can submit the form.

All selected interests are submitted together with the interests preset under **General**.
