---
title: Formulaire newsletter avec intérêts sélectionnables
lead: Les lecteurs choisissent désormais eux-mêmes les intérêts auxquels ils s'abonnent, p. ex. des newsletters individuelles, affichés sous forme de liste ou de cartes avec image et description.
---

Dans le bloc **Formulaire newsletter**, ajoutez à une étape un champ de type **Sélection d'intérêts**. Les lecteurs y choisissent les intérêts de la liste Mailchimp sélectionnée sous **Général → Liste** auxquels ils souhaitent s'abonner. Sélectionnez d'abord la liste pour que ses intérêts soient chargés.

- **Libellé :** le titre affiché au-dessus des intérêts, p. ex. « Quelles newsletters souhaitez-vous recevoir ? »
- **Options d'intérêt :** une option par intérêt. Chaque option reçoit un nom (prérempli avec le nom de l'intérêt Mailchimp), une description et une image facultative.
- **Affichage :** afficher les intérêts sous forme de **liste** simple avec des cases à cocher ou de **grille de cartes**.
- **Obligatoire :** les lecteurs doivent sélectionner au moins un intérêt avant de pouvoir envoyer le formulaire.

Tous les intérêts sélectionnés sont transmis avec les intérêts prédéfinis sous **Général**.
