---
title: Wählen Sie, wie Abo-Upgrades verrechnet werden
lead: Eine neue Karte «Abo-Pläne» in den Einstellungen bestimmt, ob bei einem Upgrade die volle Preisdifferenz zwischen altem und neuem Plan verrechnet wird oder nur das ungenutzte Restguthaben der laufenden Periode angerechnet wird.
---

Sie finden die neue Option unter **Einstellungen → Abo-Pläne**:

- **Aus (Standard):** Es ändert sich nichts. Bei einem Upgrade wird das ungenutzte Restguthaben der laufenden Periode angerechnet, der Betrag hängt also davon ab, wie viel Zeit noch verbleibt.
- **Ein:** Das Upgrade kostet immer die Differenz zwischen dem neuen und dem aktuellen Plan-Preis – unabhängig davon, wann innerhalb der Periode das Upgrade erfolgt.

Auf der Website übernimmt das Upgrade-Formular neu zudem den Betrag aus dem gewählten Plan, damit der angezeigte Preis sofort zur Auswahl passt.
