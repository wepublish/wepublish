---
title: Was ist neu in We.Publish
lead: Das Editor-Dashboard zeigt Ihnen ab jetzt, was sich mit jedem Update ändert – inklusive Aufgaben, die Ihre Aufmerksamkeit brauchen.
---

Ab sofort bringt jedes We.Publish-Update ein kurzes, verständliches Changelog
mit, das Sie direkt hier im Editor lesen können.

- **Mitteilungen** auf dem Dashboard listet die neuesten Änderungen, die
  neuesten zuerst.
- Manche Änderungen brauchen einen manuellen Schritt von Ihnen (zum Beispiel
  einen neuen Block auf einer Seite einfügen). Diese werden oben auf dem
  Dashboard hervorgehoben und bleiben sichtbar, bis jemand aus Ihrem Team
  bestätigt, dass die Aufgabe erledigt wurde.

Für diesen Eintrag ist nichts zu tun – er sagt nur Hallo. 👋
