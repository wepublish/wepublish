From now on, every We.Publish update comes with a short, plain-language changelog
that you can read right here in the editor.

- **What's new** on the dashboard lists the latest changes, newest first.
- Some changes need a manual step from you (for example adding a new block to a
  page). Those are highlighted at the top of the dashboard and stay visible until
  someone on your team confirms that the task has been completed.
