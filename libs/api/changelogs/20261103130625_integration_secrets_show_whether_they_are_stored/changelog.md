---
title: Integration settings show whether a key or password is stored
lead: Fields for API keys, webhook secrets and passwords in the integration settings now say whether a value is stored. Leaving such a field empty keeps the stored value.
---

For security, the editor never shows a stored key or password, so these fields always look empty. Until now you could not tell whether anything was stored at all.

Now each of these fields says either **«Stored (hidden) – leave empty to keep it»** or **«Not set»**. This applies to the mail provider, payment providers, Mailchimp sync, AI, spam protection (challenge) and ProLitteris. For Google Analytics, the upload area says when credentials are stored.

To replace a value, type the new one and save. A field you leave empty keeps the stored value, even if you clicked into it and cleared it.
