---
title: Les intégrations indiquent si une clé ou un mot de passe est enregistré
lead: Les champs des clés d'API, des secrets de webhook et des mots de passe dans les paramètres d'intégration indiquent désormais si une valeur est enregistrée. Un champ laissé vide conserve la valeur enregistrée.
---

Pour des raisons de sécurité, l'éditeur n'affiche jamais une clé ou un mot de passe enregistré : ces champs paraissent donc toujours vides. Jusqu'ici, il était impossible de savoir si une valeur était enregistrée.

Désormais, chacun de ces champs affiche **« Enregistré (masqué) – laisser vide pour le conserver »** ou **« Non défini »**. Cela concerne le fournisseur de messagerie, les fournisseurs de paiement, la synchronisation Mailchimp, l'IA, la protection anti-spam (challenge) et ProLitteris. Pour Google Analytics, la zone de dépôt indique lorsque des identifiants sont enregistrés.

Pour remplacer une valeur, saisissez la nouvelle et enregistrez. Un champ laissé vide conserve la valeur enregistrée, même si vous avez cliqué dedans et l'avez vidé.
