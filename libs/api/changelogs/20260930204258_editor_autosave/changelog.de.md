lead: Während Sie einen Artikel oder eine Seite bearbeiten, werden Ihre ungespeicherten Änderungen alle 30 Sekunden als Entwurf gespeichert. Der Editor zeigt zudem an, wann zuletzt gespeichert wurde.

- Beim automatischen Speichern wird nur ein **Entwurf** gespeichert. Veröffentlicht wird erst, wenn Sie selbst publizieren.
- Sie können weiterhin jederzeit manuell speichern.
