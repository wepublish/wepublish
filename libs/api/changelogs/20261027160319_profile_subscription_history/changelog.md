---
title: Clearer subscription overview for readers in their profile
lead: Readers can see all their subscriptions together with their latest invoices in one table, and they can manage each subscription on its own page.
actionRequired: false
---

This feature is in an early test phase and is only visible once We.Publish switches it on for your medium. Contact us if you would like to try it.

**In the profile overview**, readers see:

- each subscription with its status, start date, paid-until date and amount
- the two most recent invoices of each subscription, plus any older invoices that are still open
- a link to all invoices of the subscription

**On the page for each subscription**, readers can:

- see the plan, its status, dates, amount and any reward
- upgrade to a more expensive plan, if one is available with the same billing period
- see and change the payment method, or read a note if it cannot be changed online
- cancel the subscription or reactivate a cancelled one
- see all invoices of the subscription and pay open ones directly; cancelled invoices are hidden but can be shown
