---
title: Messages manuels – d’abord le canal de distribution, puis le modèle dans le tableau des modèles
lead: Lors de l’envoi d’un message manuel, vous choisissez d’abord s’il part par e-mail ou par lettre. Vous choisissez ensuite le modèle dans le tableau des modèles, qui ne propose que les modèles pour ce canal.
---

- **Où.** Sous « Messages manuels », à la première étape « Canal de distribution et contenu ».
- **D’abord le canal de distribution.** E-mail et lettre figurent tout en haut et peuvent toujours être choisis tous les deux. Sans intégration de lettres, il n’y a rien à choisir : le message part par e-mail.
- **Ensuite le modèle.** Un clic sur le champ ouvre le tableau des modèles avec recherche et filtres, comme pour les messages automatiques. Seuls les modèles ayant une version pour le canal choisi sont proposés.
- **Canal changé après coup.** Si le modèle choisi n’a pas de version pour le nouveau canal, il est désélectionné et une note l’indique. S’il en a une, il reste choisi.
- **Nouveau modèle.** Le bouton « Nouveau modèle » de la page disparaît. « Créer un nouveau modèle » se trouve en bas du tableau des modèles.
