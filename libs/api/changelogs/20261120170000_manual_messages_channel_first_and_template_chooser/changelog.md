---
title: Manual messages – the delivery channel first, then the template from the template table
lead: When sending a manual message you first choose whether it goes out by email or by letter. You then choose the template in the template table, which only offers templates for that channel.
actionRequired: false
---

- **Where.** Under “Manual messages”, in the first step “Delivery channel & content”.
- **The delivery channel first.** Email and letter are at the top and both can always be chosen. Without a letter integration there is nothing to choose: the message goes out by email.
- **Then the template.** A click on the field opens the template table with search and filters, as for automated messages. Only templates with a version for the chosen channel are offered.
- **Channel changed afterwards.** If the chosen template has no version for the new channel, it is deselected and a note says so. If it has one, it stays chosen.
- **New template.** The “New template” button on the page is gone. You find “Create new template” at the bottom of the template table.
