---
title: Suggestions IA pour les métadonnées SEO
lead: Dans les paramètres des articles et des pages, l'IA peut désormais suggérer le titre SEO, la description SEO, le titre et la description pour les réseaux sociaux ainsi que le slug.
---

Les suggestions se basent uniquement sur le contenu de l'article ou de la page. Rien n'est modifié tant que vous n'appliquez pas une suggestion, et « Appliquer aux champs vides » n'écrase jamais les valeurs existantes.

Les suggestions SEO utilisent l'intégration IA déjà configurée sous Intégrations → Intégration AI.
