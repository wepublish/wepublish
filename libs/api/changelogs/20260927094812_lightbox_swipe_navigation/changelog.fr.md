---
title: Lightbox d'images plus fluide avec navigation par balayage
lead: Les galeries d'images utilisant le style lightbox permettent désormais de passer d'une image à l'autre par balayage sur les appareils tactiles, et la navigation entre les images est globalement plus fluide.
---

La lightbox des galeries d'images a été améliorée :

- Les lecteurs peuvent désormais balayer vers la gauche ou la droite pour passer d'une image à l'autre sur smartphone et tablette.
- Le passage entre les images est plus fluide, avec des animations de transition en option.
- En mode plein écran, le bouton retour du navigateur ferme désormais la lightbox au lieu de quitter la page — particulièrement pratique sur mobile.
