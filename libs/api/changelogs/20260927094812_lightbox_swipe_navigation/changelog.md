The lightbox for image galleries has been improved:

- Readers can now swipe left and right to move between images on phones and tablets.
- Navigation between images is smoother, with optional slide animations.
- In fullscreen mode, the browser's back button now closes the lightbox instead of leaving the page — especially handy on mobile.
