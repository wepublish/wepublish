---
title: Modèles de pages : créer de nouvelles pages à partir d'un modèle
lead: Tu peux désormais enregistrer le contenu et les métadonnées d'une page comme modèle de page et créer de nouvelles pages à partir de celui-ci.
---

Gère tes modèles sous **Pages → Modèles de pages**. Un modèle de page contient des blocs, comme dans l'éditeur de pages, ainsi que des métadonnées telles que le titre, la description, les tags et les paramètres des réseaux sociaux.

Lorsque tu cliques sur **Nouvelle page**, tu peux choisir entre une page vide et l'un de tes modèles de pages. Une page créée à partir d'un modèle commence comme une copie de celui-ci. Tu peux la modifier librement, et les modifications ultérieures du modèle n'affectent pas les pages existantes. Dans l'éditeur de pages, **Créer un modèle à partir de la page** enregistre la page actuelle comme nouveau modèle.

Pour travailler avec les modèles de pages, le rôle d'un utilisateur doit disposer des nouvelles autorisations correspondantes (créer, modifier, supprimer). Les rôles admin et éditeur en disposent par défaut. Pour les autres rôles, ton administrateur peut les attribuer dans les rôles d'utilisateurs.
