---
title: Page templates: start new pages from a template
lead: You can now save the content and metadata of a page as a page template and start new pages from it.
actionRequired: false
---

Manage your templates under **Pages → Page Templates**. A page template contains blocks, as in the page editor, and metadata such as the title, description, tags and the social media settings.

When you click **New Page**, you can choose between a blank page and one of your page templates. A page created from a template starts as a copy of it. You can edit it freely, and later changes to the template do not affect pages that already exist. In the page editor, **Create template from page** saves the current page as a new template.

Working with page templates requires the new page template permissions (create, update, delete). The admin and editor roles have them by default. For other roles, your administrator can grant them under user roles.
