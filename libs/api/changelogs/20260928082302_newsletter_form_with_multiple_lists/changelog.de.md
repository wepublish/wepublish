---
title: Newsletter-Formular mit mehreren Listen
lead: Der Newsletter-Formular-Block kann neu mehrere Mailchimp-Listen gleichzeitig anbieten. So wählen Leser:innen selbst, welche Newsletter sie abonnieren.
---

Im Block **Newsletter-Formular** können über die neue Option **Mehrere Listen** mehrere Mailchimp-Listen hinzugefügt werden. Jede Liste erhält einen Namen, eine Beschreibung und optional ein Bild.

Die Listen können entweder als einfache **Liste** mit Checkboxen oder als **Raster mit Karten** dargestellt werden. Leser:innen müssen mindestens eine Liste auswählen, bevor sie das Formular absenden können.

Merge-Felder und Interessen stammen weiterhin aus der unter **Liste** ausgewählten Liste. Interessen werden nur übermittelt, wenn Leser:innen auch diese Liste auswählen.
