---
title: Formulaire newsletter avec plusieurs listes
lead: Le bloc formulaire newsletter peut désormais proposer plusieurs listes Mailchimp à la fois. Les lecteurs choisissent eux-mêmes les newsletters auxquelles ils s'abonnent.
---

Dans le bloc **Formulaire newsletter**, la nouvelle option **Plusieurs listes** permet d'ajouter plusieurs listes Mailchimp. Chaque liste reçoit un nom, une description et une image facultative.

Les listes peuvent être affichées sous forme de **liste** simple avec des cases à cocher ou de **grille de cartes**. Les lecteurs doivent sélectionner au moins une liste avant de pouvoir envoyer le formulaire.

Les champs de fusion et les intérêts proviennent toujours de la liste sélectionnée sous **Liste**. Les intérêts ne sont transmis que si le lecteur sélectionne aussi cette liste.
