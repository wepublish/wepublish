---
title: Mitteilungsvorlagen lassen sich sortieren, filtern und blättern
lead: Die Liste der Mitteilungsvorlagen ist jetzt eine Tabelle wie die anderen Listen im Editor. Sortieren Sie sie mit einem Klick auf eine Spaltenüberschrift, grenzen Sie sie mit Filtern ein und sehen Sie pro Vorlage, für welche Zustellkanäle sie geschrieben ist und welche Abo-Pläne sie verschicken.
---

- **Sortieren** nach Name, Verwendungszweck, Status, Beschreibung oder Betreff mit einem Klick auf die Spaltenüberschrift. Ein zweiter Klick kehrt die Reihenfolge um.
- **Filter** öffnen sich über den Knopf «Filter»: eine Suche über Name, Beschreibung und Betreff sowie Verwendungszweck, Status (verwendet oder nicht) und Abo-Plan.
- **Abo-Pläne** ist eine neue Spalte. Sie nennt die Pläne, deren automatische Mitteilungen die Vorlage verschicken. Mitteilungen des Standard-Ablaufs gehören zu keinem Plan und erscheinen dort nicht.
- **Anhänge** ist eine neue Spalte. Sie nennt die Dokumente, die einer Vorlage angehängt sind. Ein Filter grenzt die Liste auf Vorlagen mit oder ohne Anhang ein.
- Die Liste zeigt 20 Vorlagen pro Seite; unten lässt sich das ändern.
- Über «Spalten» wählen Sie, welche Spalten Sie in welcher Reihenfolge sehen. Der Name führt zur Vorlage.

Medien, für die gedruckte Briefe eingeschaltet sind, erhalten zusätzlich:

- Eine Spalte **Zustellkanäle**, die zeigt, ob eine Vorlage eine E-Mail-Version, eine Brief-Version oder beide hat.
- Die Spalten **Briefpapier** und **Zusatzseiten** für die Brief-Version. Beide lassen sich sortieren und filtern.
