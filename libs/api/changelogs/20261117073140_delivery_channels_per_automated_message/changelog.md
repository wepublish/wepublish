---
title: Automated messages show their delivery channels as checkboxes
lead: Under "Automated messages", each event with a template now shows a box per delivery channel instead of the "Also by letter" switch. Email is always on; Letter can be ticked when the template has a letter version.
actionRequired: false
---

This applies to media with printed letters switched on.

- **Email** is ticked and cannot be switched off: everyone who does not receive letters gets the email.
- **Letter** decides whether people on the letter channel get this message printed. What you had set with "Also by letter" is kept.
- If the chosen template has no letter version, **Letter** cannot be ticked. The ⓘ next to it says so. Add the letter version in the message template first.
- The template list of an event only offers templates with an email version.
- Events set to "Do not send an email" show no boxes.
