---
title: Les messages automatiques affichent leurs canaux de distribution sous forme de cases
lead: Sous « Messages automatiques », chaque événement doté d’un modèle affiche désormais une case par canal de distribution au lieu de l’interrupteur « Aussi par lettre ». L’e-mail est toujours actif ; la lettre peut être cochée si le modèle a une version lettre.
---

Cela concerne les médias pour lesquels les lettres imprimées sont activées.

- **E-mail** est coché et ne peut pas être désactivé : toute personne qui ne reçoit pas de lettres obtient l’e-mail.
- **Lettre** détermine si les personnes au canal lettre reçoivent ce message imprimé. Ce que vous aviez réglé avec « Aussi par lettre » est conservé.
- Si le modèle choisi n’a pas de version lettre, **Lettre** ne peut pas être coché. Le ⓘ à côté l’indique. Ajoutez d’abord la version lettre dans le modèle de message.
- La liste de modèles d’un événement ne propose que des modèles ayant une version e-mail.
- Les événements réglés sur « Ne pas envoyer d’e-mail » n’affichent aucune case.
