---
title: Print issues: see what each reader received
lead: The user list and the user view now show how many of the printed issues a subscription paid for have reached the reader, and which ones.
actionRequired: false
---

Available for media with the print export switched on, to staff who may see print issues.

- **User list**:
  - The «Subscriptions» tooltip adds the count to each subscription that still counts, e.g. «Basic – Active (7 / 12 issues)».
  - A new column «Issues owed» shows how many issues are still to send, summed over the reader's subscriptions. Sort by it to find the readers who are owed most.
- **User view, «Subscriptions»**: each subscription shows «7 / 12 issues». Expand it to see, under its period, every issue received: «#117 · 13.11.2026 · Print list, handed over 10.11.2026», or «Supplement 1».
- **What counts**: the running period, or for an ended subscription the latest paid one, as long as copies are still owed to it. Only lists marked as delivered count, a double issue counts twice and issues shipped before the print export are taken as received. Lifetime subscriptions show «∞».
