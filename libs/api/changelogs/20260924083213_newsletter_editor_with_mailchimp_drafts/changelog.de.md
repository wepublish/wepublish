---
title: Newsletter-Editor mit Mailchimp-Entwürfen
lead: Ein neuer Eintrag «Newsletter» im Editor erlaubt es, eine Newsletter-Ausgabe aus Blöcken zusammenzustellen, publizierte Artikel anzuteasern, die Grösse zu prüfen und die Ausgabe als Entwurf in das eigene Mailchimp-Konto zu übertragen.
---

Der Editor hat einen neuen Bereich **Newsletter**. Eine Ausgabe wird in einem visuellen Editor aus Blöcken gebaut, der die Mail genau so zeigt, wie sie gerendert wird: Artikel-Teaser, Rubrik-Balken, Text, Bilder aus der Mediathek, Buttons, Info-Boxen und eine fest verankerte Fusszeile.

- **Teaser bleiben aktuell.** Ein Teaser verweist auf einen publizierten Artikel; Titel, Kicker, Lead, Link und Bild werden bei jedem Rendern aus dem CMS gelesen. Eine Korrektur auf der Website erreicht den Newsletter automatisch.
- **Prüfung vor dem Versand.** Der Bereich «Prüfung» zeigt, wie nah die Ausgabe an der 102-KB-Grenze von Gmail ist, und warnt, wenn in der Fusszeile der von Mailchimp verlangte Abmeldelink oder die Postadresse fehlt.
- **Übertragung an Mailchimp.** «An Mailchimp» rendert die Ausgabe und erstellt einen Kampagnen-Entwurf im Mailchimp-Konto oder aktualisiert den zuvor erstellten Entwurf. Versand und Planung bleiben in Mailchimp.
- **Dynamischer Inhalt.** Jeder Block kann nur Kontakten gezeigt werden, die ein Merge-Feld oder eine Interessengruppe erfüllen, mit den bedingten Tags von Mailchimp.

Die Übertragung nutzt die unter Einstellungen › Integrationen bereits konfigurierte Mailchimp-Integration (API-Key und Publikum); eine zusätzliche Einrichtung ist nicht nötig.
