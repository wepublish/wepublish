The editor has a new **Newsletters** section. An issue is built from blocks in a visual editor that shows the mail exactly as it will render: article teasers, section bars, text, images from the media library, buttons, info boxes and a pinned footer.

- **Teasers stay current.** A teaser refers to a published article; headline, kicker, lead, link and image are read from the CMS every time the issue is rendered, so a correction on the site reaches the newsletter automatically.
- **Checks before you send.** The «Checks» panel shows how close the issue is to Gmail's 102 KB limit and warns when the footer lacks the unsubscribe link or postal address Mailchimp requires.
- **Transfer to Mailchimp.** «To Mailchimp» renders the issue and creates a draft campaign in your Mailchimp account, or updates the draft it created before. Sending and scheduling stay in Mailchimp.
- **Dynamic content.** Any block can be shown only to contacts matching a merge field or an interest group, using Mailchimp's own conditional tags.

Publishing uses the Mailchimp integration already configured under Settings › Integrations (API key and audience); no additional setup is needed.
