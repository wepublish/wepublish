---
title: Eine Seite statt der Artikelliste eines Tags zeigen
lead: Wählen Sie für einen Artikel-Tag eine Seite, und Ihre Website zeigt unter der Adresse des Tags diese Seite statt der Liste aller Artikel mit diesem Tag.
---

Beim Bearbeiten eines Artikel-Tags können Sie jetzt eine **Tag-Seite** wählen.
Wer den Tag auf Ihrer Website öffnet (etwa über einen Klick auf den Tag in einem
Artikel), sieht dann diese Seite statt der automatischen Liste der Artikel mit
diesem Tag. So können Sie einem Thema eine eigene Einstiegsseite geben, mit
Einleitung und ausgewählten Inhalten.

Lassen Sie das Feld leer, um weiterhin die Artikelliste zu zeigen. Solange die
gewählte Seite nicht publiziert ist, zeigt die Website ebenfalls die
Artikelliste.
