---
title: Zahlungsbestätigung bei jeder bezahlten Verlängerung
lead: Mitglieder erhalten die Bestätigung «Verlängerung hat geklappt» neu immer, sobald eine Verlängerungsrechnung bezahlt ist – unabhängig davon, wie bezahlt wurde. Wenn Sie eine Rechnung selbst als bezahlt markieren, können Sie entscheiden, ob die Bestätigung versendet wird.
---

Bisher ging die Bestätigung nur raus, wenn der nächtliche Job den Betrag automatisch abgebucht hat. Zahlte ein Mitglied über einen Zahlungslink oder markierten Sie die Rechnung im Editor als bezahlt, wurde keine Mail versendet.

Das ändert sich:

- Die Bestätigung geht raus, sobald eine Verlängerungsrechnung bezahlt ist: automatisch abgebucht, vom Mitglied selbst bezahlt oder von der Redaktion manuell als bezahlt markiert.
- In der Rechnungsliste eines Abos gibt es im Dialog «als bezahlt markieren» neu die Option **«Keine Zahlungsbestätigung an das Mitglied senden»** – praktisch bei Korrekturen oder Buchungen, die Sie nicht ankündigen möchten.
- Für die erste Periode eines neuen Abos wird keine Bestätigung versendet; neue Mitglieder erhalten weiterhin die Willkommensmail. Der Dialog weist Sie darauf hin, wenn das der Fall ist.
- Pro Rechnung wird die Bestätigung höchstens einmal ausgelöst – Mitglieder erhalten sie also nie doppelt für dieselbe Verlängerung.
