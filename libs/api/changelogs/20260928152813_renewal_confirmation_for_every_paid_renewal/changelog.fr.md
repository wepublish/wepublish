---
title: Confirmation de paiement pour chaque renouvellement payé
lead: Les membres reçoivent désormais la confirmation « Le renouvellement a fonctionné » dès qu'une facture de renouvellement est payée, quel que soit le mode de paiement. Lorsque vous marquez vous-même une facture comme payée, vous pouvez décider si la confirmation doit partir.
---

Jusqu'ici, la confirmation ne partait que lorsque le traitement nocturne encaissait le montant automatiquement. Si un membre payait via un lien de paiement ou si vous marquiez la facture comme payée dans l'éditeur, aucun e-mail n'était envoyé.

Ce qui change :

- La confirmation part dès qu'une facture de renouvellement est payée : encaissée automatiquement, payée par la personne elle-même ou marquée comme payée manuellement par la rédaction.
- Dans la liste des factures d'un abonnement, la fenêtre « marquer comme payée » propose désormais l'option **« Ne pas envoyer de confirmation de paiement au membre »** — utile pour des corrections ou des écritures que vous ne souhaitez pas annoncer.
- Aucune confirmation n'est envoyée pour la première période d'un nouvel abonnement ; les nouveaux membres reçoivent toujours l'e-mail de bienvenue. La fenêtre vous le signale le cas échéant.
- La confirmation est déclenchée au maximum une fois par facture : les membres ne la reçoivent jamais deux fois pour le même renouvellement.
