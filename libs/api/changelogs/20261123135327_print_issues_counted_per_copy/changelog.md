---
title: Print issues: count per period or per copy
lead: Under Settings › Print issues you now choose how printed issues are counted. Per period (as before), a subscription receives every issue published while its period runs. Per copy, it stops once the period has received the number of issues it is worth.
actionRequired: false
---

Available for media with the print export switched on.

- **Per period** (default, unchanged): a paid or open period receives every issue shipped while it runs, even more than it is worth. If it ends with fewer, the missing copies follow afterwards.
- **Per copy**: every delivered copy counts. Once the running period has received its number, the subscription gets no further issue until its next period starts. It appears among the skipped readers as «Quota received». If a period ends with fewer copies, the missing ones still follow, as before.
- The number of issues a period is worth comes from «Issues per year (print)» or the plan's «Printed issues per period». Counting per copy only works while «Issues per year» is above 0.
- Subscriptions from bexio (gifts, brokers, institutions) are counted the same way. The bexio overview of a print list shows how many recipients were skipped because their period already had its number.
