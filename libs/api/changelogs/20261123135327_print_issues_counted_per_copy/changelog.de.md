---
title: Druckausgaben: pro Periode oder pro Exemplar zählen
lead: Unter Einstellungen › Druckausgaben wählt ihr jetzt, wie gedruckte Ausgaben gezählt werden. Pro Periode (wie bisher) erhält ein Abo jede Ausgabe, die während seiner Periode erscheint. Pro Exemplar ist Schluss, sobald die Periode die Zahl Ausgaben erhalten hat, die sie wert ist.
---

Verfügbar für Medien, bei denen der Druckexport eingeschaltet ist.

- **Pro Periode** (Standard, unverändert): Eine bezahlte oder offene Periode erhält jede Ausgabe, die während ihrer Laufzeit erscheint, auch mehr als sie wert ist. Endet sie mit weniger, werden die fehlenden Exemplare nachgeliefert.
- **Pro Exemplar**: Jedes gelieferte Exemplar zählt. Hat die laufende Periode ihre Zahl erreicht, bekommt das Abo keine Ausgabe mehr, bis seine nächste Periode beginnt. Es erscheint bei den übersprungenen Leser:innen als «Kontingent erhalten». Endet eine Periode mit weniger Exemplaren, werden die fehlenden wie bisher nachgeliefert.
- Wie viele Ausgaben eine Periode wert ist, kommt aus «Ausgaben pro Jahr (Druck)» oder aus «Gedruckte Ausgaben pro Periode» des Abo-Plans. Die Zählung pro Exemplar wirkt nur, wenn «Ausgaben pro Jahr» grösser als 0 ist.
- Abos aus bexio (Geschenke, Broker, Institutionen) werden gleich gezählt. Die bexio-Übersicht einer Druckliste zeigt, wie viele Empfänger:innen übersprungen wurden, weil ihre Periode die Zahl schon erreicht hat.
