---
title: Export and import the website theme
lead: The theme of your website (colours and typography) can now be exported to a file and imported again, for example to copy it to another website or to keep a backup.
actionRequired: false
---

**Website Settings → Theme**

- **Export theme** downloads the colours and typography as they are in the form, together with the fonts the typography uses.
- **Import theme** loads such a file into the form. Nothing is changed until you click **Save**. Fonts from the file that your website does not have yet are added to its fonts when you save.
- Lighter and darker shades that were calculated from a colour are now stored fully opaque. Before, they were saved partly transparent by mistake.
