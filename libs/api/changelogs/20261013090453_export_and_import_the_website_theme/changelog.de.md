---
title: Website-Theme exportieren und importieren
lead: Das Theme der Website (Farben und Typografie) lässt sich neu in eine Datei exportieren und wieder importieren, etwa um es auf eine andere Website zu übertragen oder als Sicherung.
---

**Website-Einstellungen → Theme**

- **Theme exportieren** lädt die Farben und die Typografie so herunter, wie sie im Formular stehen, zusammen mit den Schriften, welche die Typografie verwendet.
- **Theme importieren** lädt eine solche Datei ins Formular. Geändert wird erst, wenn Sie auf **Speichern** klicken. Schriften aus der Datei, welche die Website noch nicht hat, werden beim Speichern zu ihren Schriften hinzugefügt.
- Hellere und dunklere Farbtöne, die aus einer Farbe berechnet werden, werden neu vollständig deckend gespeichert. Bisher wurden sie irrtümlich teilweise transparent gespeichert.
