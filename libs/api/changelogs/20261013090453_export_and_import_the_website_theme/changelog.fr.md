---
title: Exporter et importer le thème du site
lead: Le thème de votre site (couleurs et typographie) peut désormais être exporté dans un fichier et importé à nouveau, par exemple pour le copier vers un autre site ou en garder une sauvegarde.
---

**Paramètres du site → Thème**

- **Exporter le thème** télécharge les couleurs et la typographie telles qu'elles figurent dans le formulaire, avec les polices utilisées par la typographie.
- **Importer le thème** charge un tel fichier dans le formulaire. Rien n'est modifié avant que vous cliquiez sur **Enregistrer**. Les polices du fichier que votre site n'a pas encore sont ajoutées à ses polices lors de l'enregistrement.
- Les nuances plus claires et plus foncées calculées à partir d'une couleur sont désormais enregistrées entièrement opaques. Auparavant, elles étaient enregistrées par erreur partiellement transparentes.
