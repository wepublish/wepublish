---
title: Block templates: reuse groups of blocks across articles and pages
lead: You can now save a set of content blocks as a reusable block template and insert it into any article or page with the new "Block Template" block.
actionRequired: false
---

Manage your templates under **Content Blocks → Block Templates**. You can create, rename, edit and delete them there, using the same block editor as for articles and pages.

To use a template, add the **Block Template** block to an article or page and select a template:

- **Linked:** (default) the block displays the template's current content. When you change the template, every article and page that uses it updates automatically.
- **Use content:** copies the template's blocks into the article or page. You can then edit them freely, and later changes to the template will no longer affect them.

To work with block templates, a user's role needs the new block template permissions (create, update, delete). Your administrator can grant these under user roles.
