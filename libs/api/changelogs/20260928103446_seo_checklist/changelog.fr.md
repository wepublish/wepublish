- Chaque étape comprend une courte explication et, si utile, un lien direct, par exemple vers Google Search Console ou le Google News Publisher Center.
- Coche les étapes effectuées. La liste indique à toute l'équipe qui a effectué une étape et quand.
- Certains points sont vérifiés automatiquement sur ton site en ligne : le sitemap, les entrées Google News, le flux RSS ainsi que le nom et le logo de ta publication.
