---
title: Search engines get more accurate information about your content
lead: The structured data your website gives Google and other search engines now credits every author of an article, includes when it was last updated and reports event statuses correctly.
actionRequired: false
---

- Articles with several authors now list all of them, not only the first one.
- Articles and pages tell search engines when they were last updated, so updated content can be shown as such.
- Cancelled, postponed and rescheduled events are reported with their status, so search results no longer show them as taking place as planned.
- Image sizes are given in the form search engines expect, and images are no longer labelled with the wrong file format.
