---
title: Geschenkcodes
lead: Leser:innen können bald ein Abo verschenken. Der Kauf ist fertig, das Einlösen folgt in einer späteren Version. Bis dahin bleibt die Funktion ausgeschaltet.
---

Davon seht ihr noch nichts. Geschenkcodes werden pro Medium eingeschaltet,
sobald sich ein Code einlösen lässt. Bis dahin ändert sich weder im Editor noch
auf eurer Website etwas.

Wenn Geschenkcodes eingeschaltet sind:

- Unter **Abo-Pläne → Geschenkangebote** legt ihr fest, was Leser:innen
  verschenken können: einen Abo-Plan mit einer Laufzeit, einen Namen, eine
  Beschreibung, ein Bild und wie viele Monate der Code einlösbar ist (leer
  heisst unbegrenzt). Der Preis ist immer der aktuelle Preis des Plans für
  diese Laufzeit.
- Jedes Angebot hat eigene Zahlungsmethoden. Stripe, Stripe Checkout, Payrexx
  und Mollie nehmen Geschenkzahlungen an, Bexio-Rechnungen noch nicht.
- Mit **Code vor der Zahlung ausstellen** erhalten Käufer:innen den Code
  direkt nach der Bestellung. Kommt die Zahlung nicht, wird der Code nach
  14 Tagen storniert. Bis dahin kann er aber bereits eingelöst worden sein.
- Im Block **Abonnieren** wählt ihr die Geschenkangebote aus. Leser:innen sehen
  dann den Umschalter «Abonnieren / Verschenken», wählen ein Angebot, geben den
  Namen der beschenkten Person und auf Wunsch eine Nachricht ein und bezahlen.
- Ihre Codes finden Käufer:innen im Profil unter «Meine Gutscheine». Dort
  können sie eine offene Bestellung auch bezahlen.
- Unter **Abo-Pläne → Geschenkcodes** stehen alle verkauften Codes mit Status,
  Käufer:in, beschenkter Person und Zahlung. Ihr könnt einen Code stornieren
  oder seine Rechnung als bezahlt markieren. Beim Stornieren wird kein Geld
  zurückerstattet; das macht ihr weiterhin beim Zahlungsanbieter.

E-Mails und PDF-Gutscheine für Geschenkcodes gibt es noch nicht.
