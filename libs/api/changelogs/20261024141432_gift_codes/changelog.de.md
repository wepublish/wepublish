---
title: Geschenkcodes, und Gratis-Abos mit einem Rabattcode von 100 %
lead: Abos und Abo-Wechsel, die ein Rabattcode von 100 % gratis macht, klappen jetzt. Geschenkcodes sind im Editor bereit; Website und Einlösen folgen später, bis dahin bleibt die Funktion ausgeschaltet.
---

Ab sofort auf allen Medien: Kostet ein neues Abo oder ein Abo-Wechsel
CHF 0, etwa wegen eines Rabattcodes von 100 % oder weil das Guthaben des
bisherigen Abos den ganzen Wechsel deckt, wird es direkt bestätigt, ohne
Umweg über den Zahlungsanbieter. Bisher scheiterten solche Bestellungen beim
Anbieter.

Geschenkcodes werden pro Medium eingeschaltet, sobald sich ein Code einlösen
lässt. Bis dahin ändert sich für sie weder im Editor noch auf eurer Website
etwas. Auf der Website können Leser:innen noch nichts verschenken; das
Kaufformular und ein eigener Geschenk-Block kommen später.

Wenn Geschenkcodes eingeschaltet sind:

- Unter **Geschenke → Geschenkangebote** legt ihr fest, was sich verschenken
  lässt: einen Abo-Plan mit einer Laufzeit, einen Namen, eine Beschreibung,
  ein Bild und wie viele Monate der Code einlösbar ist (leer heisst
  unbegrenzt). Der Preis ist immer der aktuelle Preis des Plans für diese
  Laufzeit.
- Jedes Angebot hat eigene Zahlungsmethoden. Stripe, Stripe Checkout, Payrexx
  und Mollie nehmen Geschenkzahlungen an, Bexio-Rechnungen noch nicht.
- Mit **Code vor der Zahlung ausstellen** erhalten Käufer:innen den Code
  direkt nach der Bestellung. Kommt die Zahlung nicht, wird der Code nach
  14 Tagen storniert.
- Mit **Rabattcodes erlauben** können Käufer:innen einen Rabattcode des Plans
  eingeben. Ein Code von 100 % macht das Geschenk gratis, und der
  Geschenkcode wird sofort ausgestellt.
- **Automatisch verlängern** legt fest, ob das mit einem Code gestartete Abo
  nach der geschenkten Laufzeit weiterläuft und mit welcher Zahlungsmethode
  des Plans. Jeder Code behält die Einstellung, mit der er verkauft oder
  erstellt wurde.
- Unter **Geschenke → Geschenkcodes** stehen alle Codes mit Status,
  Käufer:in, wer ihn eingelöst hat, dem Namen der beschenkten Person und der
  Zahlung. Ihr könnt nach Zahlung (bezahlt oder unbezahlt) und nach Herkunft
  (Kauf oder von Admin erstellt) filtern, einen Code stornieren oder seine
  Rechnung als bezahlt markieren. Beim Stornieren wird kein Geld
  zurückerstattet; das macht ihr weiterhin beim Zahlungsanbieter.
- Mit **Codes erstellen** in derselben Liste verteilt ihr Codes ohne Kauf,
  zum Beispiel an Anlässen: Angebot wählen, Anzahl (bis 500) und optional den
  Namen der beschenkten Person. Die Codes gelten sofort und lassen sich auf
  einmal kopieren.
- Ein Code kann auch die offene Rechnung eines bestehenden Abos mit demselben
  Plan und derselben Laufzeit bezahlen. Die Website bietet das noch nicht an.
  Die Liste zeigt, welche Rechnung ein Code bezahlt hat, mit Link zum Abo.

E-Mails und PDF-Gutscheine für Geschenkcodes gibt es noch nicht.
