---
title: Geschenkcodes, und Gratis-Abos mit einem Rabattcode von 100 %
lead: Abos und Abo-Wechsel, die ein Rabattcode von 100 % gratis macht, klappen jetzt. Geschenkcodes lassen sich mit zwei neuen Blöcken auf deiner Website verkaufen und einlösen; sie werden pro Medium eingeschaltet.
---

Das gilt ab sofort auf allen Medien: Kostet ein neues Abo oder ein
Abo-Wechsel CHF 0, wird es direkt bestätigt, ohne Umweg über den
Zahlungsanbieter. Das ist etwa bei einem Rabattcode von 100 % der Fall oder
wenn das Guthaben des bisherigen Abos den ganzen Wechsel deckt. Bisher
scheiterten solche Bestellungen beim Anbieter.

Geschenkcodes werden pro Medium eingeschaltet. Solange sie aus sind, ändert
sich bei den Geschenkcodes weder im Editor noch auf deiner Website etwas.

Wenn Geschenkcodes eingeschaltet sind:

- Unter **Geschenke → Geschenkangebote** legst du fest, was sich verschenken
  lässt: einen Abo-Plan mit einer Laufzeit, einen Namen, eine Beschreibung,
  ein Bild und wie viele Monate der Code einlösbar ist (leer heisst
  unbegrenzt).
- Jedes Angebot hat einen eigenen Preis. Das Formular setzt den Preis des
  Plans für die gewählte Laufzeit ein und zeigt an, wenn das Geschenk
  günstiger oder teurer ist als das Abo. Das Abo, das ein Code startet,
  kostet weiterhin den normalen Preis des Plans.
- Jedes Angebot hat eigene Zahlungsmethoden. Stripe, Stripe Checkout, Payrexx
  und Mollie nehmen Geschenkzahlungen an, Bexio-Rechnungen noch nicht.
- Käufer:innen sehen ihren Code, sobald die Zahlung eingegangen ist. Eine
  Bestellung, die unbezahlt bleibt, wird nach 14 Tagen storniert.
- Mit **Rabattcodes erlauben** können Käufer:innen einen Rabattcode des Plans
  eingeben. Mit einem Code von 100 % ist das Geschenk gratis, und der
  Geschenkcode wird sofort ausgestellt.
- **Automatisch verlängern** legt fest, ob das mit einem Code gestartete Abo
  nach der geschenkten Laufzeit weiterläuft und mit welcher Zahlungsmethode
  des Plans. Jeder Code behält die Einstellung, mit der er verkauft oder
  erstellt wurde.
- Unter **Geschenke → Geschenkcodes** stehen alle Codes mit Status,
  Käufer:in, wer ihn eingelöst hat, dem Namen der beschenkten Person und der
  Zahlung. Du kannst nach Zahlung (bezahlt oder unbezahlt) und nach Herkunft
  (Kauf oder von Admin erstellt) filtern, einen Code stornieren oder seine
  Rechnung als bezahlt markieren. Beim Stornieren wird kein Geld
  zurückerstattet; das machst du weiterhin beim Zahlungsanbieter.
- Mit **Codes erstellen** in derselben Liste verteilst du Codes ohne Kauf,
  zum Beispiel an Anlässen: Angebot wählen, Anzahl (bis 500) und optional den
  Namen der beschenkten Person. Die Codes gelten sofort und lassen sich auf
  einmal kopieren.
- Beim Einlösen entscheidet We.Publish selbst, was passiert. Hat die
  einlösende Person bereits ein nicht gekündigtes Abo mit demselben Plan und
  derselben Laufzeit, bezahlt der Code dessen offene Rechnung oder die
  nächste Laufzeit. Sonst startet der Code ein neues Abo mit der
  Verlängerungseinstellung des Angebots. Die Zahlungsmethode eines Abos
  ändert sich dabei nie. In der Liste siehst du, welche Rechnung ein Code
  bezahlt hat, mit Link zum Abo.
- Der Block **Geschenkcodes verkaufen** verkauft Geschenkcodes auf deiner
  Website. Du wählst, welche Angebote er in welcher Reihenfolge zeigt, welche
  Registrierungsfelder nicht eingeloggte Käufer:innen ausfüllen, ob nach dem
  Namen der beschenkten Person gefragt wird und ob ein Rabattcode eingegeben
  werden darf. Bezahlt wird mit denselben Zahlungsmethoden und
  Weiterleitungen wie beim Abonnieren.
- Im Block **Geschenkcode einlösen** geben Leser:innen einen Code ein. Wer
  nicht eingeloggt ist, kann sich im selben Formular einloggen oder
  registrieren. Danach zeigt der Block, ob der Code ein neues Abo gestartet,
  ein bestehendes verlängert oder eine offene Rechnung bezahlt hat.
- Im Block **Abonnieren** fügt **Auf das Einlösen von Geschenkcodes
  hinweisen** neben der Abo-Auswahl den Link «Willst du ein Geschenkabo
  einlösen? Hier klicken.» ein. Er führt auf die Seite, die du wählst, meist
  die mit dem Einlöse-Block.

E-Mails und PDF-Gutscheine für Geschenkcodes gibt es noch nicht, und im
Profil auf der Website sehen Käufer:innen ihre Codes noch nicht.
