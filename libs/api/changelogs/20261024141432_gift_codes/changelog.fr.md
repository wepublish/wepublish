---
title: Codes cadeaux
lead: Vos lecteur·rice·s pourront bientôt offrir un abonnement. L’achat est prêt, l’utilisation d’un code suivra dans une version ultérieure. D’ici là, la fonction reste désactivée.
---

Vous ne voyez encore rien de tout cela. Les codes cadeaux sont activés par
média dès qu’un code peut être utilisé. D’ici là, rien ne change ni dans
l’éditeur ni sur votre site.

Une fois les codes cadeaux activés :

- Sous **Plans d’abonnement → Offres cadeaux**, vous définissez ce que les
  lecteur·rice·s peuvent offrir : un plan d’abonnement avec une durée, un nom,
  une description, une image et le nombre de mois pendant lesquels le code est
  utilisable (vide signifie sans limite). Le prix est toujours le prix actuel
  du plan pour cette durée.
- Chaque offre a ses propres méthodes de paiement. Stripe, Stripe Checkout,
  Payrexx et Mollie acceptent les paiements de cadeaux, les factures Bexio pas
  encore.
- Avec **Émettre le code avant le paiement**, l’acheteur·euse reçoit le code
  juste après la commande. Si le paiement n’arrive pas, le code est annulé
  après 14 jours, mais il a peut-être déjà été utilisé.
- Dans un bloc **S’abonner**, vous choisissez les offres cadeaux à afficher.
  Les lecteur·rice·s voient alors un sélecteur « S’abonner / Offrir »,
  choisissent une offre, saisissent le nom de la personne qui reçoit le cadeau
  et, si elles le souhaitent, un message, puis paient.
- Les acheteur·euse·s retrouvent leurs codes dans leur profil, sous
  « Mes bons cadeaux », et peuvent y payer une commande en attente.
- **Plans d’abonnement → Codes cadeaux** liste tous les codes vendus avec leur
  statut, l’acheteur·euse, la personne qui reçoit le cadeau et le paiement.
  Vous pouvez annuler un code ou marquer sa facture comme payée. L’annulation
  ne rembourse pas l’argent ; le remboursement se fait toujours chez le
  prestataire de paiement.

Il n’y a pas encore d’e-mails ni de bons PDF pour les codes cadeaux.
