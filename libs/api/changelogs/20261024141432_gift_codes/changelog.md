title: Gift codes
lead: Readers will be able to buy a subscription as a gift. Buying is ready, redeeming a code comes in a later release, so the feature stays switched off until then.
actionRequired: false
---

You won't see any of this yet. Gift codes are switched on per medium once
redeeming a code is possible. Until then, nothing changes in the editor or on
your website.

Once gift codes are switched on:

- Under **Subscription plans → Gift offers** you create what readers can
  give: one subscription plan with one duration, a name, a description, an
  image and how many months the code can be redeemed (empty means unlimited).
  The price is always the plan's current price for that duration.
- Each offer has its own payment methods. Stripe, Stripe Checkout, Payrexx and
  Mollie can take gift payments; Bexio invoices cannot yet.
- **Issue the code before payment** gives the buyer the code right after
  ordering. If the payment never arrives, the code is canceled after 14 days,
  but it may have been redeemed by then.
- In a **Subscribe** block you pick the gift offers to show. Readers then see
  a "Subscribe / Give as a gift" switch, choose an offer, enter the
  recipient's name and an optional message, and pay.
- Buyers find their codes in their profile under "Meine Gutscheine", and can
  pay an open order from there.
- **Subscription plans → Gift codes** lists every sold code with its status,
  buyer, recipient and payment. You can cancel a code or mark its invoice as
  paid. Cancelling does not refund the money; refunds still happen at the
  payment provider.

There are no emails or PDF vouchers for gift codes yet.
