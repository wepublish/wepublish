title: Gift codes, and free subscriptions with a 100 % discount code
lead: Subscriptions and upgrades that a 100 % discount code makes free now go through. Gift codes are ready in the editor; the website side and redeeming a code come later, so gift codes stay switched off until then.
actionRequired: false
---

Already active on every medium: a new subscription or an upgrade that costs
CHF 0, for example with a 100 % discount code or because the credit from the
current subscription covers the whole upgrade, is now confirmed right away
without going to the payment provider. Until now these orders failed at the
provider.

Gift codes are switched on per medium once a code can be redeemed. Until then,
nothing about them changes in the editor or on your website. Readers cannot
buy a gift on the website yet; the purchase form and a separate gift block
follow later.

Once gift codes are switched on:

- Under **Gifts → Gift offers** you set up what can be given: one
  subscription plan with one duration, a name, a description, an image and
  how many months the code can be redeemed (empty means unlimited). The price
  is always the plan's current price for that duration.
- Each offer has its own payment methods. Stripe, Stripe Checkout, Payrexx and
  Mollie can take gift payments; Bexio invoices cannot yet.
- **Issue the code before payment** gives the buyer the code right after
  ordering. If the payment never arrives, the code is canceled after 14 days.
- **Allow discount codes** lets buyers enter a discount code of the offer's
  plan. A 100 % code makes the gift free, and the code is issued at once.
- **Renew automatically** decides whether the subscription started with a
  code continues after the gift period, and with which of the plan's payment
  methods. Each code keeps the setting it was sold or created with.
- **Gifts → Gift codes** lists every code with its status, buyer, who redeemed
  it, the recipient name and the payment. You can filter by payment (paid or
  unpaid) and by source (purchase or created by an admin). You can cancel a
  code or mark its invoice as paid. Cancelling does not refund the money;
  refunds still happen at the payment provider.
- **Create codes** in the same list hands out codes without a purchase, for
  example at events: pick an offer, how many codes (up to 500) and optionally
  a recipient name. The codes are valid right away and can be copied in one
  go.
- A code can also pay the open invoice of an existing subscription with the
  same plan and duration. The website does not offer this yet. The code list
  shows which invoice a code paid, linked to the subscription.

There are no emails or PDF vouchers for gift codes yet.
