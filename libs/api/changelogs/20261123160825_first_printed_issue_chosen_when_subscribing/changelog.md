---
title: Print issues: new subscribers choose their first issue
lead: Where the subscribe page asks for it, a new subscriber chooses whether the subscription starts with the current printed issue or the next one. The print lists follow that choice.
actionRequired: false
---

Available for media with the print export switched on, on websites that show the choice («Abo-Start», for now on Zwölf).

- **Which issue is current**: the current issue is the latest one shipped by today; the next one is the first with a later ship day. If you haven't created the next issue yet, the reader sees «upcoming issue» without a number.
- **Current issue**: the reader receives it even though the subscription started after it shipped. They are in the next supplement of that issue. If the issue is already closed, unlock it first, then create a supplement. The copy counts toward the subscription's first period.
- **Next issue**: the reader is left out of supplements of the current issue, also as an advance copy. The print list summary counts them as «Subscription starts later».
- **In the subscription**: «First printed issue from» shows the day the subscription's printed issues start, and you can correct or clear it. Empty means every issue from the subscription start, as before.
