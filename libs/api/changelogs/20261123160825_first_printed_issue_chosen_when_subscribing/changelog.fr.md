---
title: Numéros imprimés : les nouveaux abonné·e·s choisissent leur premier numéro
lead: Là où la page d’abonnement le demande, un·e nouvel·le abonné·e choisit si l’abonnement commence avec le numéro imprimé actuel ou le prochain. Les listes d’impression en tiennent compte.
---

Disponible pour les médias dont l’export imprimé est activé, sur les sites qui affichent ce choix («Abo-Start», pour l’instant chez Zwölf).

- **Quel numéro est actuel** : le numéro actuel est le dernier paru ; le prochain est le premier dont la date de parution est plus tardive. Si vous n’avez pas encore saisi le prochain numéro, le choix affiche «prochain numéro» sans numéro.
- **Numéro actuel** : le·la lecteur·trice le reçoit, bien que l’abonnement ait commencé après sa parution. Il·elle figure dans le prochain complément de ce numéro. Si le numéro est déjà clos, déverrouillez-le d’abord, puis créez un complément. L’exemplaire compte pour la première période de l’abonnement.
- **Prochain numéro** : le·la lecteur·trice est exclu·e des compléments du numéro actuel, y compris comme exemplaire anticipé. Le récapitulatif de la liste d’impression le compte comme «L’abonnement commence plus tard».
- **Dans l’abonnement** : «Premier numéro imprimé dès le» indique à partir de quel jour les numéros imprimés de l’abonnement comptent ; vous pouvez corriger ou vider la date. Vide signifie, comme jusqu’ici : chaque numéro dès le début de l’abonnement.
