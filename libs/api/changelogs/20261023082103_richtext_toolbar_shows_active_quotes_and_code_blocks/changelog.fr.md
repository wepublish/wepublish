---
title: La barre d’outils de texte signale les citations et blocs de code actifs
lead: Les boutons citation et bloc de code de la barre d’outils de texte s’allument désormais lorsque le curseur se trouve dans une citation ou un bloc de code, comme le faisaient déjà les boutons gras et lien.
---

- Chaque bouton de la barre d’outils de texte, de la barre d’outils des tableaux et du menu de mise en forme a désormais un nom. Les lecteurs d’écran annoncent ainsi ce qu’il fait, au lieu de simplement « bouton ».
