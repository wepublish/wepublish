---
title: Kopf- und Fusszeile des Briefpapiers visuell bearbeiten
lead: Kopf- und Fusszeile Ihres Briefpapiers bearbeiten Sie jetzt wie eine Vorlage, visuell oder als HTML, auf einem Blatt so breit wie der gedruckte Brief.
---

- **Visuell oder HTML.** Jede Zeile im **Briefpapier** hat einen Umschalter «Visuell | HTML» wie im Vorlagen-Editor. Visuell stehen Fett, Listen, Ausrichtung, Schriftgrösse, Farbe, Links und Bilder aus der Mediathek zur Verfügung.
- **Massstabsgetreu.** Die Zeile erscheint so breit wie ein A4-Blatt und so hoch, wie Sie sie einstellen. Eine rote Linie zeigt, wo die gedruckte Zeile endet; was darunter steht, wird nicht gedruckt.
- Wie bisher zeigt die Vorschau einen Musterbrief auf Ihrem Briefpapier so, wie er gedruckt wird.
