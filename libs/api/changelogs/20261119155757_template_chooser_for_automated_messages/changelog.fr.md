---
title: Le modèle d’un message automatique se choisit dans le tableau des modèles
lead: Le modèle d’un événement de flux ou d’un message de compte ne se choisit plus dans une liste de noms. Un clic sur le champ ouvre le tableau des modèles avec recherche et filtres, pour choisir selon l’usage, l’objet, la description et plus encore.
---

- **Où.** Sous « Messages automatiques » : pour chaque événement d’un flux et chaque message « Compte et connexion ».
- **Ce que vous voyez.** Nom, usage, objet, description et pièces jointes. Si les lettres imprimées sont activées, aussi les canaux de distribution.
- **Restreint à l’événement.** Le tableau s’ouvre sur les modèles rédigés pour ce type d’événement, par exemple les modèles de facture pour « Création de facture ». « Réinitialiser les filtres » les affiche tous.
- **La recherche et les filtres** fonctionnent comme dans la liste des modèles de message.
- **Choisir.** Cliquez sur une ligne ou sur son bouton ✓ ; le choix est enregistré aussitôt. « Ne pas envoyer de message » retire le modèle de l’événement.
- « Créer un nouveau modèle » ouvre un nouveau modèle dans un autre onglet.

Comme auparavant, seuls les modèles avec une version e-mail sont proposés.
