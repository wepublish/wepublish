---
title: Choosing a template for an automated message opens the template table
lead: The template of a flow event or an account message is no longer picked from a list of names. A click on the field opens the template table with search and filters, so you can choose by purpose, subject, description and more.
actionRequired: false
---

- **Where.** Under “Automated messages”: every event of a flow and every message under “Messages for account & login events”.
- **What you see.** Name, purpose, subject, description and attachments. With printed letters switched on, also the delivery channels.
- **Narrowed to the event.** The table opens showing the templates written for this kind of event, for example invoice templates for “Invoice creation”. “Reset Filter” shows all of them.
- **Search and filters** work as in the list of message templates.
- **Choosing.** Click a row or its ✓ button; the choice is saved at once. “Send no message” removes the template from the event.
- “Create new template” opens a new template in another tab.

As before, only templates with an email version are offered.
